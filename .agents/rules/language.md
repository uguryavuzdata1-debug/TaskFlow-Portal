# Language Requirement: Strict English

- ALL user interfaces, menus, buttons, modals, table headers, forms, notifications, status badges, tooltips, and messages MUST be strictly in English.
- Never use Turkish in client-facing UI elements, labels, placeholders, or system status panels.
- Any upcoming modules, reports, system status views, and alerts must be created exclusively in English.
- Preserve technical API keys, user identifiers, and database column names as-is, but all presentation layers must be in English.
